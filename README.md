# Apaint

## What is Apaint?

Apaint is a simple yet powerful drawing application built with Java. It is designed to offer users an intuitive interface to unleash their creativity while providing essential drawing tools. This project is a personal endeavor to enhance my Java skills and contribute to the open-source community.

APaint is **Free and Open-Source Software (FOSS)**. It aims to grow with community feedback and collaboration.

## Features

- **Brush Tool**: Create freehand sketches with customizable brush sizes.
- **Shape Tools**: Draw predefined shapes like rectangles, circles, and lines.
- **Color Picker**: Choose your colors from a built-in color palette or use custom RGB values.
- **Undo/Redo**: Never lose your progress with multiple levels of undo and redo functionality.
- **Canvas Zoom**: Zoom in and out for detailed work.
- **Save and Load**: Save your artwork as PNG or JPEG and load your previous projects.

## Installation
### Prerequisites
- **Java 24 JRE or later**: Apaint is built using Java, so you need it to use the app (if you play minecraft, you dont need to do anything in javas website as you already have everything needed).
You can get JRE from [here](https://adoptium.net/temurin/releases/?version=24) if you dont have it. or download it from your package manager if on Linux.

### Steps
1. Download JAR from the releases tab.
2. Run the downloaded JAR file with java.

## Bug Reporting
If you encouter something wrong while using the app, do not hesitate to open a github issue, after all this project is built by community. 
### Steps to report bug
1. Open issues tab under this repoistory
2. erase the 2 (state:open) and (is:issue) tags
3. Press: (New issue)

### How to get me to respond to your bug
1. Make sure your issue title is accurate
2. make a detailed description of the following :
- What did you do to get the bug
- System details
- Java JRE Version
- What did you expect to happen and what actually happened
- Screenshots of the application
3. have the correct tag of (bug), otherwise your issue will be closed and not solved.
